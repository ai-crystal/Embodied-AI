# 系统篇

> 从大模型到机器人：感知、学习与行动

这本书把每一层拆到公式与实现：逆运动学的多解与奇异位形、相机模型与手眼标定、6D 位姿与力闭合、模仿学习与扩散策略、强化学习与仿真、运动规划与 TAMP、VLA 的动作头与实时性、数据规模化、腿足与人形、灵巧手与触觉，最后落到系统集成与评测。

附录：A 数学与工具速查、B 术语中英对照、C 参考文献、D 工具链速查。

## 怎么读

- 从头读：六篇有依赖，顺序最省力。
- 只做 VLA：第 1、3 章建立背景，跳到第 13 章，缺模仿学习补第 9 章，缺数据补第 14 章。
- 只做抓取：第 2、4、5、11、16 章。
- 判断 demo：第 3 章 3.6 节、第 20 章。
