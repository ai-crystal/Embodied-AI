# 具身智能技术·入门篇

> 从零开始，看懂机器怎么动手

这一册只回答一个问题：一台机器要把桌上的杯子拿起来，中间到底发生了什么。六篇十八章，每个环节给一个直觉、一组具体数字、两三个失败场景。不推公式，不列论文，目标是把整条链路铺开，让第一次接触机器人的读者读完能看懂论文的实验部分，也能对一段演示视频提出像样的问题。

## 读完能做什么

- 看懂一篇机器人论文在解决什么问题，实验部分的三个数字（试验次数、场景数、是否换过物体）意味着什么。
- 看演示视频时知道该追问什么：有没有长镜头、失败率多少、换物体换背景还成不成、人工干预有没有计数。
- 知道要动手做一个最小系统先做什么：标定、手眼、抓取检测、规划、力控、日志回放。
- 对产业有个基本判断：谁在做本体、谁在做模型、钱从哪来、哪些是演示、哪些已经能连续跑。

## 这本书不讲的

推导与实现细节不在本书范围。逆运动学为什么有多组解、扩散策略的去噪怎么推、VLA 的动作专家怎么接在视觉语言主干后面，这些只给结论和直觉，想往下走顺着附录 B 的论文读原文即可。
